# session-sync — 2 拠点セッション同期モード

このコマンドを打ったプロジェクトを、複数の Claude Code セッション
(例: 自宅 = local, 出先 = web) で交互に開発する前提の運用を起動する。
同時編集は基本しない前提で、文脈は `SESSION_LOG.md` (追記式) 経由で
引き継ぐ。

以下を **今すぐ順番に** 実行してください。

---

## Step 1 — セッション開始 (必須)

並列で:

1. `git status` — unclean な状態が無いか確認
2. プロジェクトルートの `SESSION_LOG.md` の末尾 200 行程度を Read
   - 存在しなければ「初回セッション」と判断し、ユーザーに新規作成の
     可否を確認 (§ 新規プロジェクト参照)
3. プロジェクトルートに `HANDOFF.md` があれば読み、プロジェクト固有
   のルールを把握 (作業ブランチ、命名規則、ノード / 依存の制約等)

続いて:

4. `git pull --rebase` の実行可否をユーザーに確認
   (unclean なら stash してから)

読み終わったら 5〜10 行で報告:

- 直近 1〜2 エントリの要約
- 前回「次にやること」のうち今回引き受けるべき項目
- 未確定 / 悩みどころで、まずユーザーに聞くべき事
- 今セッションが local か web か
  (環境から判別、迷ったらユーザーに確認)

---

## Step 2 — 作業中に守るルール (プロジェクト共通)

- **破壊的 git 操作** (`push --force`, `reset --hard`, ブランチ削除等)
  は都度ユーザー確認
- **push は必ずユーザー確認** を挟む (共有状態への変更)
- **実機 / 外部環境依存のタスクに直面したら**:
  - **local セッション** → 実行して結果を SESSION_LOG に記録
  - **web セッション** → 実装せず SESSION_LOG に
    「local への検証依頼」として書き、次ターンに委ねる
  - (例: DCC 実機、特定 GPU、ローカルファイル、有償 API キー等)
- プロジェクト固有ルール (作業ブランチ、命名、ノード制約、
  ファイル同期義務 等) は `HANDOFF.md` を優先する

---

## Step 3 — セッション終了 (ユーザーが終わると言ったとき、
        または大きな作業単位が完了したとき)

1. `SESSION_LOG.md` の末尾に新エントリを追記。テンプレ:

   ```
   ## YYYY-MM-DD (web|local) — <一行タイトル>

   ### やったこと
   - <箇条書き>

   ### 検討した代替案
   - <採用しなかった選択肢と理由。無ければ「特になし」>

   ### 悩みどころ / 未確定
   - <次のセッションが判断する点、実機確認待ち等>

   ### 次にやること
   - [ ] (担当: web|local) <具体的なアクション>
   ```

   日付は Bash で `date +%Y-%m-%d` を叩くか、ユーザーに聞く
   (harness 内部で `Date.now()` が使えないケースがあるため)。

2. ログ更新は **実装コミットとは別コミット**、
   `chore(session-log): <一行サマリ>` の形式で。
3. push の実行はユーザー確認を挟む。

---

## セッション判別ヒント

- DCC 実機 (Maya / Blender / Unreal / Unity 等)、特定 GPU、
  ローカルファイルアクセス、有償ローカルサービスなどが必要な環境
  かどうかで判断
- 分からなければユーザーに:
  「このセッションは local (自宅) と web (出先) のどちらですか?」

---

## 新規プロジェクトでの導入

1. プロジェクトルートに `SESSION_LOG.md` を新規作成
   (このコマンド初回実行時、無ければ Claude が作成を提案する)
2. 必要ならプロジェクト固有ルールを `HANDOFF.md` にまとめる
3. 以降、セッション開始時に `/session-sync` を打つだけで OK

このコマンド自身は user-level (`~/.claude/commands/session-sync.md`)
にも設置してあるので、`.claude/commands/session-sync.md` を
プロジェクトに置いていない他のプロジェクトからも呼び出せる。
